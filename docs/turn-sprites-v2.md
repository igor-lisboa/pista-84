# Turn sprite artwork v2

Generated using the built-in imagegen tool, with `web/assets/vehicle-atlas-v1.png` as the vehicle/style reference and a transparent background. The project artifact is [vehicle-turns-v2.png](../web/assets/vehicle-turns-v2.png). The original atlas is preserved for straight poses.

The new sheet contains 16 complete sprites: mild and strong right turn poses for each of eight vehicles. The game mirrors those poses for left turns and scales each complete frame uniformly. It does not shear or rotate a rear sprite. Cell bounds are defined in `src/sprites.js` to preserve all wheels, mirrors and bodywork; the generated sheet is 1254 by 1254 pixels with alpha transparency.

## Generation prompt

```text
Create a production sprite atlas for a retro 16-bit pseudo-3D racing game. Reference image is the existing atlas: preserve vehicle identities, colors, shading and pixel art fidelity. Output transparent RGBA PNG, exactly 4 columns by 4 rows in equal cells, each vehicle centered with generous transparent margins and consistent tyre ground baseline. NO text, labels, borders, shadows outside the cars, scenery or UI. These are TURN SPRITES, true newly drawn rear THREE-QUARTER views, with visible side doors, side windows and both wheels on the visible side, rigid undistorted bodywork. Every vehicle is driving AWAY from the viewer and turning toward screen RIGHT, nose pointing upper-right at about 20 degrees yaw. Rear bumper remains low in frame and the entire LEFT SIDE of body is visible extending toward upper-right. Not a front view, not pure profile, not a skewed/sheared straight rear image. Maintain original elevated rear chase-camera perspective. Each pair of neighboring columns shows SAME vehicle SAME scale at two yaw angles: left column mild RIGHT turn (12 degrees), right column strong RIGHT turn (25 degrees). Mirror versions will be generated by game code for left turn. Layout EXACTLY: row1 col1 cream/beige classic VW Beetle mild turn, col2 same Beetle strong turn, col3 pale green VW Brasilia wagon mild turn, col4 same Brasilia strong turn. Row2 col1 blue Gol rounded compact hatchback mild, col2 same strong, col3 orange Palio hatchback mild, col4 same strong. Row3 col1 white/blue urban motorbike and helmeted rider mild right lean, col2 same stronger right lean, col3 red midengine Ferrari-like sports coupe mild turn, col4 same strong turn. Row4 col1 tan square offroad SUV with rear spare tire mild turn, col2 same strong, col3 purple superbike and rider mild right lean, col4 same strong. All 16 silhouettes separate and fully contained within their cells, matching scale of same vehicle across its two poses. Make real side panels and side window geometry apparent, preserve rear lamps, bumpers, rooflines.
```
